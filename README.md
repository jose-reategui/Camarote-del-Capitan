# 🏴‍☠️ El camarote del capitán

SPA responsive para conversar con el capitán Jack Sparrow mediante Google Gemini.

Desarrollada con HTML, CSS, JavaScript y Vercel Functions. Incluye navegación con History API y seis tests unitarios con Vitest.

🌐 [Abrir la aplicación](https://camarote-del-capitan.vercel.app)

📖 [Ver la documentación completa](Documentacion/README.md)

## Organización

- **Desarrollo:** código fuente, función serverless y tests.
- **Documentacion:** instrucciones, capturas y registro del uso de IA.
